# Boliviq iOS Screens — Canons BB01–BB19

80 static iPhone mockup screens (390x844pt) covering the core flow of all 19 Boliviq canons.

## Structure

- `screens/` — 80 `.dc.html` Design Component files, one per screen, named `BB{canon}-{seq}-{Name}.dc.html`
  (e.g. `BB05-02-Lead-Detail.dc.html` = Canon BB05 CRM & Pipeline, screen 2).
- `canvas.json` — layout manifest (artboard positions + compliance/annotation sticky notes) for the
  Claude Design canvas editor.
- `boliviq-ios-canons-1-19.html` — the fully seeded, standalone canvas file (self-contained, opens in
  any browser as a pan/zoom canvas of all 80 screens).
